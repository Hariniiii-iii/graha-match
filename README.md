# Graha Match

A love and marriage compatibility website based on Vedic astrology, set against an interactive 3D solar system built with Three.js.

## Features
- Enter name, date of birth, birth time, birth place and raasi for two people
- Moon sign (raasi) and nakshatra worked out from birth details, with a manual raasi option
- Traditional 36-point Ashtakoota matching: Varna, Vashya, Tara, Yoni, Graha Maitri, Gana, Bhakoot and Nadi
- Scores for love, marriage harmony, and family and health
- Animated 3D planets that react to mouse movement
- Runs fully in the browser, so no birth details are stored or sent anywhere

## Tech
HTML, CSS, JavaScript, Three.js

## Live demo
https://hariniiii-iii.github.io/graha-match/

## Note
Moon position is approximate, and Yoni and Vashya scoring is simplified. For entertainment and guidance only, not a substitute for a full horoscope reading by an astrologer.
